## ✨ Core Features

* **🤖 AI Luau Code Generation:** Generate highly optimized, production-ready Roblox Luau scripts instantly using natural language prompts.
* **🔍 Smart Debugging & Refactoring:** Scan your scripts to automatically detect syntax errors, identify logical bugs, and get instant performance-tuning recommendations.
* **🎨 Modern Dockable UI:** A lightweight, sleek interface that integrates perfectly into your Roblox Studio environment as a native widget.
* **📚 Roblox API Deep Integration:** Trained explicitly on up-to-date Roblox documentation, Services (`DataStoreService`, `TweenService`, etc.), and physics behaviors.

## 📁 Repository Structure

Based on the structure of this repository, here is a layout of the core modules:

* `api/` — Serverless API endpoints handling AI inference processing and requests.
* `js/` — Frontend application logic, core routing, and chat dashboard scripts.
* `tools/` — Automation scripts, compilers, and development utilities.
* `icon/` — Visual branding assets and plugin interface icons.
* `terms.html` — Legal compliance: Official Terms of Service.
* `privacy.html` — Legal compliance: Official Privacy Policy.
* `vercel.json` — Vercel optimization, header controls, and routing configurations.
